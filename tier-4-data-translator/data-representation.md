# Tier 4 — Data Translator

## 1. Introduction

Computers store and process information in digital form. Different types of information require different representations.

## 2. Identifying Data Types

| Information | Data Type |
|---|---|
| Victor | Text (String) |
| 30 | Integer |
| 150000.50 | Float |
| Yes | Boolean (True/False) |

## 3. How Computers Represent Data

Computers represent information using binary digits (0 and 1).

The process is:

**Real-world Information → Data Representation → Binary Data → Computer Storage**

For example:
- Names are represented using character encoding.
- Numbers are represented digitally.
- Yes/No information can be represented using Boolean values.

## 4. Reasoning Challenge

If a customer's account balance is stored incorrectly, the system might display or process the wrong amount.

This could lead to incorrect financial records and transaction errors.

## 5. Conclusion

This exercise demonstrates that computers need information to be represented in a format they can store and process.

Different types of information require different data representations.
