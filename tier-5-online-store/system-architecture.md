# Tier 5 — Online Store Architecture

## 1. Introduction

An online store allows customers to select products, place orders and receive order confirmations.

The system follows these stages:

**CUSTOMER INPUT → PROGRAM → INSTRUCTIONS → DATA PROCESSING → STORED DATA → OUTPUT**

## 2. Customer Input

The customer provides:
- Selected product.
- Quantity.
- Delivery information.
- Payment information.

## 3. Application / Program

The online store receives the customer's information and follows programmed instructions to process the order.

## 4. Instructions

The program performs the following tasks:

- Identify the selected product.
- Check product availability.
- Calculate the total price.
- Process the order.
- Update the order records.

## 5. Data Processing

Example:

- Product price: ₦50,000
- Quantity: 2
- Total: ₦100,000

The program multiplies the product price by the quantity to calculate the total amount.

## 6. Stored Data

The system stores important order information, including:

- Customer details.
- Product information.
- Quantity.
- Total amount.
- Order status.

## 7. Result / Output

After processing the order, the system displays a confirmation message.

Example:

"Order confirmed. Total: ₦100,000."

## 8. Conclusion

An online store uses programs and instructions to receive customer information, process orders, store important data and produce results.

This demonstrates how different components of a computer system work together to solve real-world problems.
